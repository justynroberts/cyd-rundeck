# cyd-rundeck

ESP32 "Cheap Yellow Display" (ESP32-2432S028R) firmware that monitors and
interacts with a Rundeck server: running jobs, recent executions, ack /
abort actions.

Sibling of [`pagerduty-cyd`](../pagerduty-cyd) — see [`CLAUDE.md`](./CLAUDE.md)
for the consolidated learnings (CYD hardware, LVGL pitfalls, WiFi captive
portal) that should be carried over.

## Status

Stub repo. Firmware not yet started.
